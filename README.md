# SimpMusic — форк

Личный форк FOSS-клиента YouTube Music [maxrave-dev/SimpMusic](https://github.com/maxrave-dev/SimpMusic)
для Android на базе Kotlin Multiplatform под лицензией GPL-3.0.

## Что это

Этот репозиторий является личным форком проекта
[maxrave-dev/SimpMusic](https://github.com/maxrave-dev/SimpMusic), который поддерживает Surikat1703.
Код плеера, парсинга YouTube Music, рендереров текстов и остальной базовой функциональности
поступает из апстрима через слияние с веткой `upstream/dev`.
Лицензия GPL-3.0 сохраняется без изменений, а весь оригинальный код принадлежит `maxrave-dev`.

## Сборки

Готовые сборки публикуются только в разделе Releases этого репозитория:

https://github.com/Surikat1703/SimpMusic/releases

Релизный APK собирается из ветки `dev` в GitHub Actions
(workflow `Build fork APK (FOSS, arm64)` с ручным запуском) и публикуется одним файлом
`SimpMusic-FOSS-arm64.apk`. Параметры сборки:

- архитектура: только `arm64-v8a`;
- вариант: только FOSS (`isFullBuild=false`, без Sentry, Google Cast и Last.fm);
- подпись: постоянный ключ форка (`applicationId` — `cn.kuwo.player`).

Установленное приложение можно обновить только следующей сборкой, подписанной тем же ключом.
Накатить релиз форка поверх официального APK от `maxrave-dev` (или обновить форк сборкой
из апстрима) нельзя — Android отклонит установку из-за несовпадения подписи.
При переходе с другой сборки требуется предварительное удаление приложения и чистая установка;
последующие релизы из этого репозитория устанавливаются поверх с сохранением данных.

## Что изменено в форке

### Вкладка Мой микс

- Вкладка «Мой микс» переработана: добавлен полноэкранный анимированный фон
  (AGSL-шейдер на Android 13+ и Canvas-поле на более старых версиях Android и Desktop),
  управляемый состоянием воспроизведения, и собственный встроенный плеер.
- Нажатие на обложку во встроенном плеере открывает стандартный экран «Сейчас играет».
- Под плеером расположены три карточки: «Мой супермикс» (скруглённый прямоугольник, шрифт `serif`),
  «Любимые треки» (форма сердца, `cursive`) и «Все настроения» (форма-клякса с коллажем обложек, `monospace`).
- Страница не скроллится вертикально; штатный мини-плеер на вкладке скрыт, так как
  у вкладки есть собственный плеер.
- Карточка «Все настроения» открывает штатную полку «Миксы для вас».
- Выбор микса на полке «Миксы для вас» сразу запускает его воспроизведение и возвращает
  на вкладку «Мой микс», а карточка «Все настроения» получает белую обводку.

### Кэш и офлайн

- Автокэш персонального микса работает через WorkManager: держит заданное число треков
  в офлайне, обновляется по расписанию и по требованию, в первую очередь заменяя
  прослушанные или пропущенные треки.
- Настройки автокэша перенесены со вкладки «Мой микс» в «Настройки».
- В «Настройках» добавлен раздел «Лишнее на устройстве», который подсчитывает скачанные треки
  вне плейлистов и вне плана кэша и удаляет их по подтверждению.
- Экран «Любимые треки» сначала показывает локально лайкнутое и скачанное и лишь затем
  синхронизируется с YouTube; пустой или геоблокированный ответ больше не затирает
  кэшированный список (двусторонняя синхронизация с YouTube и отправка в Google сохранены).
- Исправлено офлайн-воспроизведение: очередь не подставляет позицию из сохранённой очереди,
  шаффл не перемешивает старт новой очереди, а лайки не перештамповывают `favoriteAt`
  (из-за этого порядок «Любимых» был произвольным).
- В `core/` добавлены защита записи состояния загрузки (устраняет лаги интерфейса во время
  скачивания) и удаление файла кэша при удалении загрузки.

### Прочее

- В «Настройках» (раздел интерфейса) добавлена настройка вкладки по умолчанию:
  «Главная», «Мой микс», «Аналитика», «Медиатека» или «Поиск».
- Локальная история прослушивания автоматически включается при первом запуске
  (иначе вкладка аналитики скрыта) и отключается в «Настройках» («История прослушивания»).
- Убран встроенный апдейтер, который вёл на репозиторий апстрима; обновление выполняется
  вручную установкой APK из Releases этого репозитория.
- Сборка ограничена FOSS-вариантом (`isFullBuild=false`, без Sentry, Google Cast и Last.fm)
  для архитектуры `arm64-v8a` с собственным ключом подписи.

## Слияние с апстримом

В репозитории `origin` указывает на форк, а `upstream` — на `maxrave-dev/SimpMusic`.
Для обновления базы апстрима используются команды:

```bash
git fetch upstream
git merge upstream/dev
```

Изменения форка сосредоточены в каталогах `composeApp/` и `androidApp/`.
Каталог `core/` является собственным сабмодулем форка (`Surikat1703/core`), поэтому его
мержат отдельно: сначала выполняется слияние `maxrave-dev/core` в `Surikat1703/core`,
затем обновляется ссылка на коммит сабмодуля в этом репозитории (подробнее см. [FORK.md](FORK.md)).

## Сборка из исходников

Требования и параметры локальной сборки:

- JDK 21;
- инициализированный сабмодуль `core/`;
- FOSS-конфигурация по умолчанию в `androidApp/build.gradle.kts` (`isFullBuild=false`).

Команды сборки для Windows из корня репозитория:

```powershell
.\gradlew.bat :androidApp:assembleDebug
.\gradlew.bat :androidApp:assembleRelease
```

Локальная сборка использует конфигурацию подписи `apktoolm` (`androidApp/testkey.jks`).
Готовые APK-файлы сохраняются в каталогах:

- `androidApp/build/outputs/apk/debug/` — отладочная сборка;
- `androidApp/build/outputs/apk/release/` — релизная сборка (`arm64-v8a`).
